# Подбор изображений для новости — дизайн

- Дата: 2026-11-15
- Версия продукта после реализации: 2.4.0
- Предыстория: подбор картинок был в расширении до 2.0.0 и удалён вместе с ключами
  Pixabay и старым хранилищем. Возвращаем задачу на других условиях: без ключей
  сервисов, с записью в папку установки и с настройкой числа фотографий.

## 1. Задача и границы

В панели на странице редактора Дзена появляется кнопка **«Изображения»**. По клику
расширение берёт заголовок статьи, ищет подходящие фотографии в Bing и Яндексе,
скачивает от 5 до 10 штук (число задаётся в настройках), каждую не тяжелее 3 МБ,
и кладёт их в папку установки:

```
<папка установки>/news/<заголовок новости>/01.jpg
<папка установки>/news/<заголовок новости>/02.png
...
```

Заголовок можно поправить в окне подбора. Поиск запускается сразу, окно показывает
прогресс. Папка `news` создаётся при первом успешном подборе; папка новости — только
когда есть хотя бы одна готовая картинка.

Вне рамок: Google (без браузера отдаёт пустую выдачу), Wikimedia и API с ключами,
проверка лицензий, загрузка картинок в Дзен, выбор другой папки для каждой новости,
докачка в уже существующую папку новости.

## 2. Почему окно, а не панель

Панель — контент-скрипт на странице Дзена. У неё нет доступа к хранилищу расширения,
где лежит рукоять папки, и она не может вызвать `chrome.permissions.request`.
Окно расширения имеет происхождение расширения: оно читает ту же рукоять папки
установки, что и автообновление, просит права и пишет файлы через File System Access API.

Клик по кнопке панели отправляет фону сообщение, фон открывает окно `images.html`
размером примерно 560 на 720. Если окно уже открыто, оно получает фокус.

## 3. Компоненты и интерфейсы

### 3.1. `src/extension-src/images.js` — чистые функции

Подключается в контент-скрипт (до `content.js`), в окно подбора и в юнит-набор.
Экспортирует объект `DzenImages`:

| Имя | Поведение |
| --- | --- |
| `MIN_COUNT = 5`, `MAX_COUNT = 10`, `DEFAULT_COUNT = 8` | Границы настройки |
| `MAX_IMAGE_BYTES = 3 * 1024 * 1024` | Потолок одной картинки |
| `MAX_CANDIDATES = 40` | Потолок ссылок после склейки выдач |
| `clampCount(value)` | Целое от 5 до 10; пустое или мусор — 8 |
| `decodeEntities(text)` | `&quot;`, `&#34;`, `&#x22;`, `&amp;`, `&#38;`, `&#x26;`, `&lt;`, `&gt;`, `&#x2F;`, `\/` |
| `parseBing(html)` | Массив ссылок из `murl` в обеих формах кавычек |
| `parseYandex(html)` | Массив ссылок из `origUrl` в обеих формах кавычек |
| `isHttpUrl(url)` | Только `http:` и `https:`, без логина и пароля, длина до 2048 |
| `mergeCandidates(lists, limit)` | По очереди из каждого списка, без повторов, только `isHttpUrl`, не больше лимита |
| `sanitizeFolderName(title, fallback)` | Убирает `\ / : * ? " < > |` и управляющие символы, точки и пробелы по краям, служебные имена Windows, режет до 80 знаков; пусто — `fallback` |
| `nextFreeName(base, used)` | Если `base` занято, добавляет ` (2)`, ` (3)` и так далее |
| `imageType(bytes)` | `jpg`, `png`, `webp`, `gif` по сигнатуре; иначе `null` |
| `fileName(index, ext)` | `01.jpg`, `10.webp` — два знака на номер |
| `guessTitle(doc, editor)` | Заголовок из поля «Заголовок», затем из видимого `h1`, затем первая непустая строка редактора, затем `doc.title` без хвостов «— Дзен», «— Яндекс Дзен», «| Дзен»; пробелы схлопнуты, не больше 160 знаков |

`guessTitle` не вставляет HTML и не читает атрибуты как разметку: только текст.

### 3.2. `src/extension-src/images.html` и `images-page.js`

Окно подбора. Разметка: поле «Заголовок новости», строка «Сколько фото: N (меняется
в настройках)», кнопка «Подобрать» в покое и «Остановить» во время работы, строка
состояния, кнопки «Выбрать папку установки», «Разрешить запись» или «Разрешить
доступ» по необходимости и кнопка «Настройки», открывающая `popup.html`. Стили
встроены в `images.html`; чужие данные выводятся через `textContent`, не через
`innerHTML`. Скрипты подключаются по порядку: `update.js`, `images.js`,
`images-page.js`.

Порядок работы страницы:

1. Читает `title` из строки запроса, обрезает до 300 знаков.
2. Читает `chrome.storage.sync.get({ imageCount: DEFAULT_COUNT })` и применяет
   `clampCount`.
3. Загружает рукоять папки установки из IndexedDB (`dzr-update`, хранилище
   `handles`, ключ `install-dir`). Нет рукояти — кнопка «Выбрать папку установки»
   с `showDirectoryPicker({ mode: "readwrite" })` и проверкой
   `DzenUpdate.installDirProblem`.
4. Проверяет `queryPermission({ mode: "readwrite" })`. Не выдано — кнопка
   «Разрешить запись», затем `requestPermission`.
5. Проверяет `chrome.permissions.contains({ origins: ["https://*/*"] })`. Не выдано —
   кнопка «Разрешить доступ к сайтам с картинками», затем
   `chrome.permissions.request({ origins: ["https://*/*"] })`.
6. Если заголовок непустой и все права готовы — сразу запускает подбор. Пустой
   заголовок — ждёт, пока его введут и нажмут «Подобрать».
7. После завершения или ошибки поле снова редактируется, кнопка «Подобрать заново»
   запускает новый подбор в новую папку.

Функции страницы, не выносимые в чистый модуль: `fetchCapped`, `searchBoth`,
`downloadPool`, `writePicked`, `start`, `stop`, `setStatus`.

### 3.3. `content.js` — кнопка панели

В `buildBar` добавляется кнопка `imagesBtn` с иконкой картинки и подписью
«Изображения»; полная подсказка — «Подобрать изображения для новости». По клику:

```js
send({ type: "openImagePicker", title: DzenImages.guessTitle(document, findEditor()) })
  .then(function (res) {
    if (!res || !res.ok) setStatus("Не удалось открыть подбор картинок: " + ((res && res.error) || "фон не ответил"));
  });
```

Кнопка не запускает перевод и не меняет выделение. `images.js` подключается в
манифесте перед `content.js`.

### 3.4. `background.js` — открытие окна

Новый тип сообщения `openImagePicker`. Заголовок приводится к строке и обрезается
до 300 знаков; адрес окна — `chrome.runtime.getURL("images.html")` с
`?title=<encodeURIComponent>`. Открывается `chrome.windows.create` с типом `popup`;
номер окна хранится в `chrome.storage.session` под ключом `imageWindowId`, а
`chrome.windows.onRemoved` удаляет ключ. Если окно с этим номером ещё существует,
вместо нового вызывается `chrome.windows.update(id, { focused: true })`. При
ошибке открытия — `chrome.tabs.create`. Ответ: `{ ok: true, windowId }` или
`{ ok: false, error }`.

Ключи API и настройки AI фон в сообщении не передаёт: заголовок статьи не секрет,
но и лишнего в ответ не кладём.

### 3.5. `update.js` — общие помощники папки

`openUpdateDb`, `withUpdateStore`, `loadDirHandle`, `saveDirHandle`,
`forgetDirHandle` переносятся из `popup.js` в `update.js` без изменения поведения и
становятся `DzenUpdate.*`. Попап переключается на них; окно картинок использует те
же функции. Это убирает вторую копию имён базы, хранилища и ключа.

### 3.6. Настройки

В `DEFAULTS` (фон) добавляется `imageCount: 8`; ключ живёт в `chrome.storage.sync`.
В настройках попапа появляется блок «Картинки для новостей» с полем
`#imageCount` (`type="number"`, `min="5"`, `max="10"`, `step="1"`) и подсказкой
«от 5 до 10». При сохранении значение приводится `clampCount`; пустое или мусор
дают 8. Окно подбора показывает значение только для чтения. Чтобы попап видел
`clampCount`, `popup.html` подключает `images.js` перед `popup.js`.

### 3.7. Сборка и манифест

`FILES` сборщика дополняется `images.html`, `images.js`, `images-page.js`.
`manifest.json` дополняет `content_scripts.js` файлом `images.js` перед
`content.js`. Новых прав в манифесте нет: `https://*/*` уже лежит в
`optional_host_permissions`.

Сейчас `options_ui` указывает на `popup.html`. В 2.4.0 он переносится на страницу
подбора: `{ "page": "images.html", "open_in_tab": true }`. Это нужно
автообновлению: `updateFileSet` уже берёт `options_ui.page` из далёкого манифеста
и разбирает скрипты страницы, поэтому `images.html` и `images-page.js` попадут в
пакет обновления без правки `update.js`. Без этого обновление на 2.4.0 принесло
бы `content.js` с кнопкой, но без окна подбора.

Попап с настройками остаётся на кнопке расширения: он по-прежнему
`action.default_popup` и в состав обновления попадает. Чтобы ссылка «Параметры
расширения» не теряла привычный вход в настройки, в окне подбора есть кнопка
«Настройки»: она открывает `popup.html` в новой вкладке через
`chrome.tabs.create`. `images.html` остаётся страницей расширения: наружу она не
открывается, `web_accessible_resources` не добавляется. Открытая как «Параметры
расширения», она показывает тот же подбор с пустым заголовком.

Сборщик при пересборке сносит папку `--out` целиком. Перед `rmSync` он переносит
существующую `<out>/news` в соседний временный путь, после копирования файлов
возвращает её на место; при ошибке копирования возвращает в `finally`. Если перенос
не удался, сборка останавливается до удаления папки. В zip папка `news` не попадает:
состав zip берётся из явного списка `FILES`.

## 4. Источники и отбор

- Bing: `https://www.bing.com/images/async?q=<query>&first=0&count=35&mmasync=1`.
- Яндекс: `https://yandex.ru/images/search?text=<query>`.
- Оба запроса идут параллельно, с `credentials: "omit"` и
  `referrerPolicy: "no-referrer"`, таймаут 15 секунд, тело выдачи читается с
  потолком 2 МБ. Ошибка одного источника не отменяет второй.
- Ссылки склеиваются по очереди, дубли по точному адресу отбрасываются, потолок —
  `MAX_CANDIDATES`.
- Каждая ссылка скачивается отдельно: таймаут 12 секунд, потолок
  `MAX_IMAGE_BYTES` по `Content-Length` и по потоку (лишнее обрывается, не занимая
  память), проверка сигнатуры `imageType`, отпечаток SHA-256 против повторов
  содержимого.
- Скачивание идёт пулом из 4 исполнителей; при наборе заданного числа остальные
  загрузки отменяются. Пропуски (403, таймаут, не картинка, тяжелее 3 МБ)
  не считаются ошибкой подбора.
- Если обе выдачи пусты или не разобрались — статус «не удалось получить ссылки»,
  папки не создаются. Если валидных картинок меньше заданного числа — пишутся
  найденные, в статусе сказано «N из M».

## 5. Папки, имена и запись

- `root.getDirectoryHandle("news", { create: true })` — один раз на подбор.
- Имя папки: `sanitizeFolderName(заголовок, "novost")`; занятое имя получает
  ` (2)`, ` (3)`; существующие файлы не перезаписываются.
- Файлы: `fileName(0, ext)` и далее, расширение берётся из `imageType`.
- Запись — `DzenUpdate.writeRel(root, "news/<папка>/<файл>", bytes)`, последовательно.
  Ошибка записи останавливает запись, в статусе — папка и число записанных файлов;
  уже записанное не удаляется.
- Папка новости создаётся после того, как собрана хотя бы одна валидная картинка.
- Путь всегда относительный и без `..`: имя папки — один сегмент, проверенный
  `sanitizeFolderName`; имя файла строится из номера и расширения.

## 6. Права и безопасность

- Рукоять папки установки — та же, что у автообновления; окно не показывает
  абсолютный путь, которого у `FileSystemHandle` всё равно нет.
- Широкое право `https://*/*` спрашивается отдельной кнопкой с объяснением: без него
  нельзя скачать картинку с чужого сайта. Отказ — статус, запросов нет.
- Сеть: только выдачи Bing и Яндекса и прямые адреса картинок; cookies не
  отправляются, `Referer` не отправляется.
- Чужой HTML не вставляется в страницу: выдачи разбираются как текст, имена и
  заголовки выводятся через `textContent`.
- Ключ API и настройки AI окно не читает и в сообщениях не передаёт.
- Перед публикацией права на изображения проверяет пользователь; в окне и README
  есть напоминание.

## 7. Ошибки и исходы

| Исход | Что видит пользователь |
| --- | --- |
| Нет рукояти папки | Кнопка «Выбрать папку установки» и объяснение |
| Нет права на запись | Кнопка «Разрешить запись»; отказ — причина, не успех |
| Нет широкого права | Кнопка «Разрешить доступ к сайтам с картинками»; отказ — причина |
| Обе выдачи пусты | «Не удалось получить ссылки на картинки», папки нет |
| Валидных меньше заданного | Записаны найденные, статус «N из M» |
| Картинка не скачалась | Пропуск, подбор продолжается |
| Ошибка записи | Статус с папкой и числом записанных файлов |
| Отмена | Загрузки прерваны, записанное остаётся |

## 8. Тесты

- Юнит-набор (`test-reliability.cjs`, новый раздел):
  - разбор Bing и Яндекса на фиксированных кусках HTML, обе формы кавычек,
    раскодирование `&amp;` и `&quot;`;
  - склейка, очередность источников, дубли, недопустимые схемы, потолок;
  - очистка имени: слэши, `..`, служебные имена Windows, длинное имя, пустое;
  - `nextFreeName`, `imageType` на сигнатурах и на HTML, `fileName`, `clampCount`;
  - `guessTitle` на подставном документе: поле «Заголовок», затем видимый `h1`,
    затем первая строка редактора, затем `doc.title` с хвостом «— Дзен»; пробелы
    схлопнуты, длина не больше 160;
  - сборщик сохраняет `news` при пересборке: временная папка с именем на
    `dzen-rewriter` и файлом `news/keep.jpg`, запуск сборщика с `--out` и
    `--no-zip`, проверка файла после сборки.
- Браузерный набор (`test-popup.cjs`, новый блок):
  - окно подбора с подставными `fetch`, рукоятью папки и памятью IndexedDB;
  - счастливый путь: ссылки из двух источников, дубль, тяжёлая картинка, HTML
    вместо картинки; проверка папки, имён, расширений и числа файлов;
  - меньше заданного числа, пустая выдача, отказ в широком праве, отказ в записи,
    отсутствие рукояти, заголовок `../../evil`;
  - настройка `imageCount` читается и ограничивается.
- Панель: кнопка «Изображения» есть; клик отправляет `openImagePicker` с заголовком
  статьи (браузерный набор панели).
- Полная регрессия всех наборов перед сдачей.

## 9. Критерии приёмки

1. Версия 2.4.0 в четырёх местах: `src/extension-src/manifest.json`,
   `package.json`, бейдж в `popup.html`, строка в `src/extension-src/README.md`.
2. В панели есть кнопка «Изображения»; клик открывает окно подбора.
3. Окно создаёт `<папка установки>/news/<заголовок>/` и кладёт туда от 5 до 10
   картинок (по настройке), каждая не тяжелее 3 МБ; файлы открываются как изображения.
4. Настройка «Сколько фото» сохраняется, читается окном и ограничена 5–10.
5. Повторная пересборка расширения и автообновление не удаляют `news`.
6. Отказы в правах, пустая выдача и нехватка картинок названы причиной; папка
   не создаётся там, где нечего писать.
7. Юнит-набор, браузерный набор и сторожа зелёные; полная регрессия зелёная.
8. Ни один ключ API и ни одна настройка AI не попадают в окно, сообщения, имена
    файлов и README-примеры.

## 10. Взаимодействие с автообновлением

- Папка `news` лежит внутри папки установки, поэтому после автообновления остаётся
  на месте: `updateFileSet` строится из манифеста и страниц, `news` в него не входит,
  обновление пишет только файлы пакета и не удаляет чужие каталоги.
- Новые файлы 2.4.0 попадают в пакет обновления через `options_ui.page =
  images.html` и разбор её скриптов; отдельного правила в `update.js` нет.
- Ручная пересборка сохраняет `news` отдельным переносом до очистки папки.
- Если пользователь выберет другую папку установки, `news` останется в прежней;
  это ожидаемо и отдельного переноса не делаем.
