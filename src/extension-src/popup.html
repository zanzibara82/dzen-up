Д Дзен Рерайтер v2.1.0

Откройте редактор статьи на dzen.ru, выделите текст и нажмите иконку внизу окна или Ctrl+Shift+Y.

Текст статьи не меняется, пока вы не нажмёте «Применить».

Русский абзац при переводе на русский не уходит в переводчик — это экономит запросы и не портит формулировки. Язык определяется по письменности и служебным словам; при сомнении текст всё равно переводится.

Когда вы копируете статью с другого сайта, вместе с текстом приезжают и ссылки — на источник, на соседние материалы. В переводе они не нужны: ссылка снимается до отправки текста переводчику, а текст ссылки остаётся на месте, чтобы фраза не рассыпалась. Режим вместе с текстом убирает и его — удобно для строки вида «Читайте также: …». Картинки внутри ссылки остаются в любом режиме.

Дописывается отдельным абзацем в самом конце статьи — но только если статья обрабатывается целиком. Работаете с фрагментом в середине — приписки не будет. Текст уходит в статью как есть, переводчик его не трогает, поэтому формулировки остаются вашими. Если приписка уже есть в тексте, второй раз не добавится.

По строке на термин: Оригинал — оставить как есть, Оригинал = Замена — подставить своё. Строки с # игнорируются. Бренды и модели не будут исковерканы переводчиком.

Глоссарий хранится локально и не ограничен 8 КБ, так что можно вписать хоть сотню терминов. Он не синхронизируется между устройствами.

По строке на сайт, строки с # игнорируются. Кнопка «Перелинковка» в панели превращает упоминания моделей в статье в ссылки на материалы этих сайтов: адрес подбирается по sitemap.xml сайта. Если карты нет — ссылка ведёт на сам сайт. Каналы Дзена вписывайте в поле ниже: у них нет sitemap.xml.

По строке на канал, строки с # игнорируются. У канала на Дзене нет sitemap.xml — карта статей собирается обходом его ленты (до ~120 самых свежих статей), заголовки сохраняются, и модель ищется по ним. Карта живёт 12 часов; обновить вручную — кнопкой ниже. Если обход не удался, ссылка ведёт на сам канал.

«Выгрузить sitemap.xml» сохраняет уже собранную карту файлом в папку загрузок — по файлу на канал. Заголовки статей записаны комментариями: в схеме sitemap для них места нет, а по адресу вида /a/… не понять, о чём статья.

По строке на правило: Термин = вариант. Слева — название для поиска, справа — его вариант в тексте. Ваши правила приоритетнее встроенных; регистр не важен, строки с # игнорируются. Текст статьи не меняется. Словарь хранится локально, не ограничен 8 КБ и не синхронизируется. Пустое поле оставляет только встроенные синонимы.

Ссылки ставятся не в первый абзац и не в соседних абзацах, не в заголовки и не больше одной на абзац. Если упоминаний моделей в тексте меньше — поставим сколько есть.

Проверка отправляет один настоящий запрос тем же путём, что и рерайт: тем же адресом, ключом и моделью. Так всплывает и неверное название модели. Запрос платный (крошечный — ответ ограничен восемью токенами), поэтому идёт только по нажатию.

Ключ OpenAI — на platform.openai.com/api-keys, OpenRouter — на openrouter.ai/keys. Адрес API указывайте до /chat/completions: расширение дописывает его само. Для своего сервиса (не OpenAI и не OpenRouter) нажмите «Проверить ключ» — расширение спросит доступ к его домену, без этого запрос не уйдёт. Локальная модель (Ollama) — адрес вида http://127.0.0.1:11434/v1: по http доступ даётся только к localhost и 127.0.0.1, ключ оставляйте пустым, ждать ответа придётся минутами — панель покажет, сколько уже идёт рерайт.

Промпт уходит в модель системным сообщением и применяется ко всей статье. Правьте его руками — стиль переключится на «Свой промпт», и выбор пресета больше не будет затирать вашу правку.
